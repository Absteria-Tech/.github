# Absteria

**Tecnología para simplificar operaciones complejas.**

Somos una empresa uruguaya de software enfocada en desarrollar tecnología útil, simple de adoptar y pensada desde la operación real.

Actualmente desarrollamos una plataforma para operaciones de última milla que centraliza pedidos, planificación de rutas, flota y choferes para ayudar a las empresas a ordenar y simplificar su distribución diaria.

Trabajamos desde Uruguay con foco en Latinoamérica.
